# Hélios · Radar de Demanda

Shows, festivais, feriados, provas e jogos que movimentam viagens, com o tempo de cada praça e a leitura de vendas × chuva × eventos. Revenue · Grupo JCA.

- Eventos e fotos vêm do Radar de Demanda atual (uma fonte só).

- Vendas: o Excel do Cubo é lido no navegador e fica só no computador de quem carregou. Este site não tem números de venda.
